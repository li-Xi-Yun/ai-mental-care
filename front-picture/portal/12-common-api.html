Common 公共接口（验证码 & 上传）
不属于独立页面，是被其他页面/组件调用的公共接口。包括验证码获取、邮件验证码发送、图片上传三个接口
1️⃣ 图形验证码 — 登录/注册时使用

🔢获取验证码图片

接口POST /common/verification/code
请求参数无
返回值Map{"image": "base64图片字符串", "key": "Redis中验证码答案的键"}
页面使用流程：
1. 弹窗打开时自动调用此接口 → 获得 image(base64) 和 key
2. 将 image 渲染为 <img src="data:image/png;base64,...">
3. 用户输入验证码后，将 code + key 传给登录/注册接口

📧发送邮件验证码

接口POST /common/verification/email
请求参数email (String, 必填, 邮箱号)
返回值void
用途：忘记密码场景 — 用户输入邮箱 → 调用此接口发送验证码 → 用户填写验证码 → 调用 PATCH /user/account 修改密码
2️⃣ 图片上传 — 个人中心头像上传时使用

🖼️图片上传接口

接口POST /common/upload/image
请求参数file (MultipartFile, 必填, 图片文件)
返回值String (图片URL，如 https://oss.example.com/avatars/xxx.jpg)
页面使用流程：个人中心 → 点击头像 → 选择图片文件 → 调用此接口上传 → 获得图片URL → 填入 UserProfileDTO.avatar → 保存资料
