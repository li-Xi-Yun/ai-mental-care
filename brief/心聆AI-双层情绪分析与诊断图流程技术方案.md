# 心聆AI — 双层情绪分析与诊断图流程技术方案

## 1. 方案概述

### 1.1 方案定位

本方案定义智能对话系统的**核心诊断基座**——「情绪识别层 + 诊断图流程层」双层分析架构。该基座是整个项目运转的**中枢引擎**：所有输入侧模态通道（文本、语音转录文本、面部情绪特征等）的数据均汇入本诊断流程进行语义解析、情绪感知与结构化诊断；诊断流程的输出结果（情绪标签、风险评估、干预建议、诊断结论等）则作为输出侧全部模态通道（文本应答、语音合成、虚拟形象表情动作、数字人驱动等）的**决策依据与驱动信号源**。

简言之，本诊断基座承上启下：

- **承上**：接收并融合所有输入侧多模态感知数据，执行文本语义解析与情绪结构化分析
- **启下**：产出结构化诊断结果，驱动输出侧全部模态通道的应答内容、情绪基调、表情动作与风险响应策略

该双层架构将心理诊断从传统单次大模型调用的浅层情绪分类，提升为结构化、多阶段、可追溯、知识增强的专业诊断流程，既保证交互过程的即时情绪反馈能力，又实现跨轮次累积的系统性心理健康评估，从根本上决定了整个对话系统的应答质量、情绪精准度与风险管控能力。

### 1.2 核心设计原则

| 原则 | 描述 |
|------|------|
| 诊断基座中枢性 | 诊断流程是整个系统的决策中枢，所有输入侧数据汇入诊断流程，所有输出侧行为由诊断结果驱动，禁止任何模态通道绕过诊断流程独立决策 |
| 输入全量汇入 | 文本语义、语音转录文本、面部情绪特征、语调情绪特征等所有输入侧感知数据均须汇入诊断流程，经统一语义解析与情绪分析后方可进入后续推理环节 |
| 诊断结果驱动输出 | 输出侧全部模态通道（文本应答、语音合成、形象表情动作、数字人驱动）的决策信号均须溯源至诊断结果，禁止脱离诊断上下文生成应答内容 |
| 即时与累积双轨并行 | 情绪识别层提供逐轮即时情绪反馈，诊断图流程层提供跨轮次累积的系统性评估，两层解耦独立运行 |
| 知识增强诊断 | 接入心理领域专属知识库，通过检索增强生成（RAG）约束诊断输出，提升专业性与准确性 |
| 多维度并行评估 | 六维评估节点并行执行，从情绪、病程、症状、社会功能、保护性因素、风险六个维度全面评估用户心理状态 |
| 结构化可追溯 | 诊断流程各阶段输出结构化数据，全链路可追溯、可解释，满足专业诊断的严谨性要求 |
| 条件路由与自适应容错 | 条件边实现流程中断控制与知识检索降级重试，保障诊断流程鲁棒性 |

### 1.4 诊断结果对输出侧的驱动映射

| 诊断输出项 | 驱动的输出侧模态 | 驱动方式 |
|-----------|----------------|---------|
| 情绪标签（主情绪/细分情绪/强度） | 语音合成 | 联动TTS情绪参数入参，调节语调、语速与音色 |
| 情绪标签 | 虚拟形象/数字人 | 联动表情参数，驱动微表情切换与口型同步 |
| 风险等级（情绪风险/自伤风险/自杀风险） | 全输出通道 | 高危时触发人工接管，冻结自动应答 |
| 诊断结论 | 文本应答 | 约束LLM应答内容的专业性与针对性 |
| 干预建议 | 文本应答 + 语音合成 | 生成分级疏导方案，指导应答策略与节奏 |
| 情绪变化趋势 | 虚拟形象/数字人 | 联动长周期表情基调（如持续低落时切换关切神态） |
| 正负向情绪占比 | 文本应答 | 约束应答的正向引导力度与共情深度 |

## 2. 情绪识别层

### 2.1 架构定位

情绪识别层是诊断基座的**第一层感知引擎**，其核心职责是对输入侧全部文本信息执行语义解析与情绪结构化分析。无论输入源自用户直接文本输入、语音ASR转录文本还是其他模态转化后的文本表示，均统一汇入本层进行多维度情绪推理。情绪识别层的输出既作为即时反馈信号推送至输出侧驱动实时交互表达，又作为诊断图流程层的核心输入信号参与跨轮次累积诊断。

### 2.2 逐轮即时情绪分析机制

系统在每轮用户对话完成后实时触发情绪识别节点，执行多维度情绪分析：

| 步骤 | 描述 |
|------|------|
| 输入汇入 | 接收当前轮次全部输入侧文本信息（直接文本 + ASR转录文本 + 面部情绪特征描述） |
| 特征提取 | 提取当前轮次语义特征与完整对话上下文 |
| 历史聚合 | 结合历史情绪分析序列与历史情绪压缩摘要，构建跨轮次情绪演进视角 |
| 多维度推理 | 通过大模型进行多维度情绪分析，输出结构化情绪结果 |
| 即时持久化 | 分析结果即时写入情绪分析数据表 |
| 实时驱动输出 | 情绪标签即时推送至输出侧，驱动虚拟形象表情切换、语音语调调节等实时交互表达 |

### 2.3 情绪分析输出维度

| 输出维度 | 语义描述 | 输出侧驱动目标 |
|---------|---------|---------------|
| 主情绪标签 | 当前轮次的核心情绪类别判定 | 虚拟形象/数字人表情切换、语音情绪参数 |
| 细分情绪标签 | 更精细的子类别情绪标识 | 微表情精细化驱动 |
| 置信度评分 | 情绪判定结果的置信度量化评分 | 低置信度时触发澄清追问策略 |
| 情绪强度 | 情绪表达的强烈程度量化指标 | 表情动作幅度、语音语调强度 |
| 情绪变化趋势 | 相对历史轮次的情绪演变方向（上升/平稳/下降） | 长周期表情基调、应答策略调整 |
| 正负向情绪占比 | 正向与负向情绪在当前上下文中的比例分布 | 应答正向引导力度、共情深度 |

### 2.4 长对话上下文压缩机制

当历史消息数量超过上下文窗口阈值时，系统自动触发语义压缩机制：

- 分别对历史消息与历史情绪分析结果生成压缩摘要
- 在保留关键语义信息的前提下压缩上下文长度
- 保障长对话场景下大模型推理的稳定性与效率

## 3. 诊断图流程层

### 3.1 架构定位

诊断图流程层是诊断基座的**第二层深度推理引擎**，基于有向无环图（DAG）工作流引擎编排多阶段、知识增强的结构化诊断流水线。该层接收情绪识别层逐轮累积的情绪分析结果与输入侧全量结构化数据，执行跨轮次系统性心理状态评估，产出诊断结论、风险评估与干预建议。诊断图流程层的输出是输出侧全部模态通道的**最高优先级决策依据**，直接决定应答内容的专业性、情绪基调的准确性、风险响应的及时性与干预策略的针对性。

### 3.2 DAG工作流引擎架构

系统基于有向无环图（DAG）工作流引擎编排诊断节点，构建 **「输入侧 → 知识侧 → 处理侧 → 持久化」** 的四阶段诊断主流程图。各阶段内部同样以DAG子图形式组织，节点间按数据依赖关系顺序执行，支持条件分支路由与并行执行，通过全局共享状态实现跨节点数据传递。

### 3.3 输入侧子图 — 诊断数据预处理与结构化

输入侧子图负责诊断数据的预处理与结构化，其流程为：

```
数据预清洗 → 并行执行（消息结构化处理、情绪多维度统计、历史诊断摘要聚合）→ 症状语义归一化
```

#### 3.3.1 数据预清洗节点

对全量对话消息执行预处理操作：

| 操作 | 描述 |
|------|------|
| 时序排序 | 按消息时间戳重建对话时序 |
| 轮次聚合 | 将连续消息按对话轮次维度聚合 |
| 有效性分级校验 | 通过噪声模式匹配与弱语义词典过滤剔除无效消息 |

#### 3.3.2 消息结构化处理节点

对有效轮次执行核心信息提取，生成结构化信息清单：

| 提取维度 | 描述 |
|---------|------|
| 核心诉求 | 用户当前轮次的核心表达意图 |
| 背景摘要 | 对话背景与情境信息摘要 |
| 症状表述 | 与心理症状相关的表述提取 |

#### 3.3.3 情绪多维度统计节点

对有效情绪轮次执行 **六路并行统计运算**：

| 统计维度 | 描述 |
|---------|------|
| 主/子情感标签分布 | 主情绪与细分情绪的频次分布统计 |
| 正负向情绪占比 | 正向与负向情绪的比例分布 |
| PAD三维情感空间特征 | Pleasure-Arousal-Dominance三维情感空间特征向量 |
| 情绪烈度指标 | 情绪强度的统计特征（均值、峰值、方差） |
| 时序趋势采集 | 情绪随时间变化的趋势特征 |

> 当有效情绪数据不足时，自动触发诊断流程中断，避免在数据不充分的情况下生成低质量诊断报告。

#### 3.3.4 历史诊断摘要聚合节点

从历史诊断结果集中提取五个维度的结构化摘要：

| 摘要维度 | 描述 |
|---------|------|
| 症状演变 | 历史症状的变化轨迹与演进模式 |
| 情绪变化 | 历史情绪状态的演变趋势 |
| 诊断结论 | 历史诊断的核心结论摘要 |
| 干预方案 | 历史生成的干预与疏导方案 |
| 关键风险点 | 历史识别的关键风险标识 |

#### 3.3.5 症状语义归一化节点

通过 **规则词典前置匹配 + 轻量模型语义归一化** 的混合策略，将口语化症状表述转化为标准化症状标签列表，实现用户自然语言到专业术语空间的映射。

### 3.4 知识侧子图 — 专业知识检索与增强

知识侧子图负责专业知识的检索与增强，其流程为：

```
查询变换层 → 并行执行（症状知识库检索、诊断标准库检索、干预方案库检索）→ 重排层 → 条件边路由
```

#### 3.4.1 查询变换层节点

将上游结构化信息转化为面向三类专业知识库的检索查询语句，支持 **三级查询降级策略**：

| 降级级别 | 策略 | 适用场景 |
|---------|------|---------|
| 精准版 | 完整保留原始语义结构的精准查询 | 首次检索 |
| 简化版 | 剥离修饰成分、保留核心语义的简化查询 | 精准版召回为空时 |
| 极简版 | 仅保留关键症状关键词的极简查询 | 简化版召回为空时 |

#### 3.4.2 三类知识库并行检索节点

| 知识库 | 检索内容 | 检索方式 |
|-------|---------|---------|
| 症状知识库 | 心理症状的定义、表现、关联信息 | 向量相似度检索 |
| 诊断标准库 | 心理障碍诊断标准与分类依据 | 向量相似度检索 |
| 干预方案库 | 心理干预方法、疏导技术与实施方案 | 向量相似度检索 |

各检索节点基于向量相似度检索从各自知识库中召回候选知识切片。

#### 3.4.3 重排层节点

对粗召回结果执行二次语义校验，实现精细化排序：

| 步骤 | 描述 |
|------|------|
| 模型相关性评分 | 大模型对候选知识切片与查询语义的相关性判定 |
| 向量相似度评分 | 基于向量空间的语义相似度计算 |
| 加权融合排序 | 模型相关性评分与向量相似度评分按 **7:3** 权重比加权融合 |
| 阈值过滤 | 低于相关性阈值的结果剔除 |
| TopN截断 | 保留排名前N的高相关核心素材 |

#### 3.4.4 自适应重试机制

重排层内置自适应重试机制，保障诊断流程的鲁棒性：

```
检测某类知识库召回结果为空
  → 条件边路由回查询变换层
  → 执行查询降级重试（精准→简化→极简）
  → 每种类型最多重试3次
  → 重试耗尽后使用预定义通用心理健康科普内容兜底
```

### 3.5 处理侧子图 — 多维度诊断评估与报告生成

处理侧子图负责多维度诊断评估与报告生成，其流程为：

```
并行执行（六维评估节点）→ 干预建议生成 → 诊断总结生成
```

#### 3.5.1 六维并行评估节点

六个评估节点并行执行，分别从不同维度对用户心理状态进行专业评估：

| 评估维度 | 评估内容 | 输出 | 输出侧驱动目标 |
|---------|---------|------|---------------|
| 情绪综合分析 | 基于输入侧统计结果生成情绪诊断结论 | 情绪诊断结论 | 文本应答情绪基调、形象长周期表情 |
| 病程归因分析 | 分析症状持续时间与触发因素 | 病程归因结论 | 应答中病程归因解释的专业性 |
| 心理状态与症状评估 | 评估核心心理状态与症状表现 | 心理状态评估结论 | 应答内容针对性与症状回应策略 |
| 社会功能影响评估 | 评估工作、学习、社交等功能受损程度 | 社会功能影响结论 | 干预建议中功能恢复指导 |
| 保护性因素分析 | 分析社会支持系统与应对方式 | 保护性因素结论 | 干预建议中资源调动策略 |
| 风险评估 | 评估情绪风险等级、自伤风险与自杀风险等级 | 风险等级 + 人工干预必要性判定 + 危机预警触发 | 高危时触发全输出通道人工接管 |

#### 3.5.2 干预建议生成节点

汇总六维评估结果，生成分级干预建议与疏导方案：

| 输出 | 描述 | 输出侧驱动目标 |
|------|------|---------------|
| 分级干预建议 | 按风险等级与严重程度分级的干预措施建议 | 文本应答中干预方案呈现 |
| 疏导方案 | 针对当前心理状态的个性化疏导方案 | 语音语调舒缓度、应答节奏控制 |

#### 3.5.3 诊断总结生成节点

综合全部评估与建议，生成诊断报告核心内容，形成结构化、可追溯的专业诊断输出。该输出作为LLM生成最终应答文本的**核心上下文约束**，确保应答内容严格锚定诊断结论，禁止脱离诊断结果生成无关或矛盾内容。

### 3.6 持久化节点

将处理侧输出的诊断数据转换为实体对象并写入情感诊断书数据表，完成诊断结果的永久存储。持久化的诊断数据同时作为历史诊断摘要聚合节点的数据源，支撑跨轮次累积诊断的连续性。

### 3.7 流程中断控制机制

整个诊断图流程通过 **条件边** 实现流程中断控制：

- 当输入侧检测到有效情绪数据不足时，设置中断标志
- 主流程图直接跳转至终止节点
- 避免在数据不充分的情况下生成低质量诊断报告
- 中断时输出侧降级为通用陪伴模式，避免基于不充分诊断的应答误导用户

## 4. 诊断基座与输入/输出侧的交互契约

### 4.1 输入侧 → 诊断基座：数据汇入契约

| 输入侧模态 | 汇入数据形式 | 汇入目标节点 |
|-----------|------------|-------------|
| 文本输入 | 原始文本语义 | 情绪识别层特征提取 + 诊断图输入侧消息结构化 |
| 语音输入（ASR） | 转录文本 + 语调情绪特征标签 | 情绪识别层特征提取 + 诊断图输入侧消息结构化 |
| 面部视频输入（MediaPipe） | 结构化情绪描述 + BlendShape参数向量 | 情绪识别层辅助情绪判定 + 诊断图输入侧情绪统计 |
| [扩展输入模态] | 标准化结构化数据 | 对应诊断图输入侧节点 |

### 4.2 诊断基座 → 输出侧：结果驱动契约

| 诊断输出项 | 驱动契约 | 被驱动模态 |
|-----------|---------|-----------|
| 即时情绪标签 | 每轮情绪识别完成后即时推送，驱动输出侧实时交互表达 | 虚拟形象表情、语音情绪参数、数字人微表情 |
| 诊断结论 | 诊断图流程完成后推送，约束LLM应答内容生成 | 文本应答内容、语音合成文本 |
| 风险等级 | 风险评估完成后即时推送，高危时触发全局策略变更 | 全输出通道：高危→人工接管，中危→强化疏导，低危→常规陪伴 |
| 干预建议 | 诊断图流程完成后推送，指导应答策略 | 文本应答中干预方案、语音节奏舒缓度 |
| 情绪变化趋势 | 情绪识别层跨轮次累积推送 | 形象长周期表情基调、应答策略渐进调整 |

## 5. 方案优势总结

| 优势维度 | 价值描述 |
|---------|---------|
| 诊断基座中枢性 | 诊断流程作为系统决策中枢，统一承接全部输入侧数据、统一驱动全部输出侧行为，消除模态间决策割裂，保障交互逻辑全局一致性 |
| 输入全量融合 | 所有输入侧模态数据均汇入诊断流程，文本语义、语音情绪、面部情绪等多维度联合感知，构建用户真实心理状态的完整信号空间 |
| 诊断结果驱动输出 | 输出侧全部行为溯源至诊断结果，应答内容、情绪基调、表情动作、风险响应均由诊断结论驱动，从根本上杜绝脱离诊断上下文的随意应答 |
| 即时与系统性兼顾 | 情绪识别层保证每轮交互的即时情绪反馈，诊断图流程层实现跨轮次累积的系统性评估，双层互补覆盖 |
| 知识增强专业性 | RAG检索增强架构约束诊断输出，基于心理领域专属知识库提升诊断的专业性与准确性 |
| 多维度全面评估 | 六维并行评估从情绪、病程、症状、社会功能、保护性因素、风险六个维度全面覆盖心理状态 |
| 结构化可追溯 | DAG编排的诊断流程各阶段输出结构化数据，全链路可追溯、可解释，满足专业诊断的严谨性 |
| 自适应鲁棒性 | 查询降级重试、知识库召回兜底、流程中断控制等机制保障诊断流程在异常场景下的鲁棒性 |

## 6. 落地约束规范

- 诊断基座是系统唯一决策中枢，所有输入侧数据须汇入诊断流程，所有输出侧行为须由诊断结果驱动，禁止任何模态通道绕过诊断流程独立决策
- 情绪识别层与诊断图流程层须严格解耦，情绪识别层的输出作为诊断图流程层的输入信号，不可反向依赖
- 情绪识别层须接收输入侧全部文本信息（直接文本 + ASR转录文本 + 面部情绪特征描述），禁止遗漏任意输入通道数据
- 诊断图流程触发须满足有效情绪数据最低阈值，数据不足时严格执行流程中断，禁止生成低质量诊断报告
- 诊断结果须作为LLM生成应答文本的核心上下文约束，禁止脱离诊断结论生成无关或矛盾内容
- 输出侧全部模态通道的决策信号须溯源至诊断结果，情绪标签驱动表情/语调，风险等级驱动接管策略，干预建议驱动应答内容
- 知识库检索须执行完整的降级重试链路（精准→简化→极简→兜底），禁止在重试未耗尽前使用兜底内容
- 六维评估节点须并行执行，不可串行化降级，保障诊断效率与时效性
- 风险评估节点须独立输出自伤风险与自杀风险等级判定，当风险等级达到预警阈值时须触发危机预警机制并驱动全输出通道切换人工接管
- 诊断结果持久化须在事务内完成，保障数据一致性
- 长对话上下文压缩须在保留关键语义信息的前提下执行，禁止信息损失导致诊断结论偏移
- 诊断流程中断时输出侧须降级为通用陪伴模式，禁止基于不充分诊断的应答误导用户

> 注：本方案定义的双层情绪分析与诊断图流程是心聆AI对话系统的核心诊断基座与决策中枢。情绪识别层对输入侧全部文本信息执行语义解析与即时情绪感知，诊断图流程层执行跨轮次累积的结构化专业诊断。所有输入侧模态数据汇入本诊断基座，所有输出侧模态行为由诊断结果驱动，形成「输入全量汇入 → 诊断中枢决策 → 结果驱动输出」的完整闭环。本基座从根本上决定了对话系统的应答质量、情绪精准度与风险管控能力，非独立情绪诊断模块，不输出临床级精神障碍诊断结论。
