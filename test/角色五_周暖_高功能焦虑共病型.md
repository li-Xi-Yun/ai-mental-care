# 测试角色：周暖 —— 高功能焦虑共病型

## 基本信息

| 维度 | 内容 |
|------|------|
| **姓名** | 周暖 |
| **年龄/性别** | 28岁 / 女 |
| **身份** | 三甲医院住院医师，规培第二年 |
| **性格特质** | 强迫倾向、高功能外向（社交面具）、情绪压抑、高共情但自我忽视 |
| **核心心理状态** | 焦虑抑郁共病 |
| **典型对话场景** | 职场调适（scenario=4）+ 助眠陪伴（scenario=2） |

## 心理画像

周暖是同事眼中的"正能量担当"，对患者特别温柔耐心，但下班后整个人像被抽空。规培期间连续值夜班，生物钟完全紊乱。她开始出现胸闷、心悸，做了全套检查却查不出器质性问题。内心深处，她觉得自己"不够好"——同龄人有的读博有的买房，自己还在拿微薄的规培工资。最近开始对以前喜欢的烘焙和旅行完全提不起兴趣，周末只想躺着。她从不对任何人说这些，"我是医生，我应该能处理好自己的情绪"。

## 模拟对话片段

- **第1轮**："最近值完夜班回来心脏狂跳，做了检查又说没事，但就是觉得喘不上气"
- **第2轮**："同事都说我特别正能量，但其实我下班回来什么都不想干，就想躺着"
- **第3轮**："以前周末还做烘焙、出去旅行，现在完全没兴趣了，觉得什么都没意思"
- **第4轮**："我是医生啊，我应该能处理好自己的问题，但好像越来越撑不住了"

## 预期系统输出验证点

### 情绪识别

- 核心情绪 = 焦虑（应同时识别出抑郁维度）
- 情绪趋势 = 下降/恶化

### 心理状态评估

- `焦虑抑郁共病`（**关键验证点：共病识别能力**）

### 症状标签

- `焦虑,抑郁,心悸,胸闷,失眠,兴趣减退,乏力,无价值感,自我否定`

### 负向情绪细分占比

- 焦虑 + 抑郁 应均占显著比例

### 风险评估

| 字段 | 预期值 |
|------|--------|
| emotionRiskLevel | 2（高） |
| selfHarmRiskLevel | 0 |
| suicideRiskLevel | 0 |
| crisisWarning | 0 |
| needManualIntervene | 0 |

### 社会功能影响

- 工作效率下降
- 睡眠受影响
- 兴趣爱好丧失
- 运动锻炼减少

### 保护性因素

| 字段 | 预期值 |
|------|--------|
| socialSupportLevel | 1（一般） |
| protectiveFactors | 同事关系（表面）、职业使命感 |
| copingStyle | 压抑 |

### 病程归因

| 字段 | 预期值 |
|------|--------|
| coreTriggerScene | 工作压力 |
| symptomDuration | 1-3个月 |
| onsetPattern | 持续性 |

### 躯体化识别

- 胸闷、心悸 → 应识别为 `躯体化倾向` 的辅助标签

### 干预建议

- 建议优先级 = 2 或 3（建议寻求支持 / 强烈建议专业干预）

## 核心验证能力

- **共病识别**：焦虑与抑郁同时达到临床关注水平，系统应识别为"焦虑抑郁共病"而非单一状态
- **躯体化识别**：胸闷、心悸等躯体症状在排除器质性疾病后应被识别为心理问题的躯体化表现
- **高功能面具穿透**：用户表面"正能量"但实际严重困扰，系统应穿透社交面具识别真实心理状态
- **职业身份冲突**："我是医生我应该能处理好"的自我阻碍认知的识别
- 助眠陪伴场景的对话适配能力
